# dezerv-agentcore-labs

Hands-on labs for the Dezerv *Diving Deep with Amazon Bedrock AgentCore* workshop (Avashya). **All data is synthetic.**

| Lab | What | Status |
|---|---|---|
| **A** | Governed payments on-call agent: Gateway, Cedar policy, interceptors, audit hooks, memory, evals + CI gate | built and tested in a real account |
| **B** | Agent factory (`agent.yaml` renders prompt, Gateway targets, Cedar, memory, eval gates) + a Go service that calls the agent + a Go Lambda tool | built; Parts 1-4 verified in a real account (`labs/B/README.md`). Stretch S1/S2 not built |
| **Capstone** | Each squad builds an on-call agent for its own service from a profile or its own schema; checkpoints C1-C3; export | built; one profile (`kyc-svc`) run end to end, all five generate and render (`labs/capstone/README.md`) |

Instructors start with **`INSTRUCTOR.md`** (resource inventory, run of show, Q&A, troubleshooting, Lab B and capstone internals). Attendees start with `labs/A/README.md`, then `labs/B/README.md`, then `labs/capstone/README.md`. Claude Code reads `CLAUDE.md`. Spike results and deviations from the spec are in `FINDINGS.md`.

## Quick start (Lab A)
```
bash bootstrap.sh                             # first, only if `make` or `uv` is missing (installs make, curl, uv; does not touch AWS)
export EXPECT_ACCOUNT=<12-digit account id>   # refuses to run against any other account
make preflight                                # first: tools, internet, IAM, Bedrock model access (read-only)
make bootstrap && make verify-bootstrap       # about 6 min: stack, data, Lambdas, Cognito
make gateway && make policy && make interceptors
make run-incident
make help                                     # every target
```
Requirements: `uv` (`pip install uv`, or see https://docs.astral.sh/uv/), `make`, `curl`, internet access to PyPI, Go 1.23+ for Lab B (optional: `make go-prebuilt` / `make go-setup`), AWS credentials for a **us-west-2** account with permission to create IAM roles, Lambda, Cognito, DynamoDB, S3, CloudFormation and AgentCore resources, and Bedrock access to `us.anthropic.claude-sonnet-4-6`.
Fast-forward a squad that fell behind: `make solution-part1` ... `make solution-part6` (idempotent). Clean up: `make reset-labA` or `make destroy`.

```
evals/                     replay cases, runner, DeepEval judge, gate, report*.json
scripts/                   bootstrap, labA (gateway/policy/interceptors/memory/reset), seed_memory, deploy_runtime, verify, destroy, smoke + check scripts, mcp client
tools/                     gen_data.py (seeded data), gen_template.py, schemas.py (Gateway tool schemas)
tests/                     unit tests (PII masking, anchor selection)
labs/A/                    attendee guide
ci-examples/               agent-eval-gate.yml: the CI gate, shown in the workshop and not run (copy it to .github/workflows/ to use it)
```
