# Dezerv AgentCore Workshop

**Build governed on-call agents for Dezerv's payments stack on Amazon Bedrock AgentCore.**

This guide covers the Dezerv-specific labs, which run alongside the AWS workshop *Diving Deep with Amazon Bedrock AgentCore*.
The AWS workshop teaches each AgentCore feature with generic examples. These labs apply the features to a realistic Dezerv incident, to Dezerv's Go services, and finally to your own squad's service.

!!! danger "All data in these labs is synthetic"
    Every transaction, user, Aadhaar number, PAN, phone number, card and UPI ID in these labs is generated by `tools/gen_data.py`.
    **Never paste real customer data, credentials or source code into a workshop account.**

## What you will build

![Lab A architecture](diagrams/lab-a-architecture.drawio)

One idea runs through the whole day: **guardrails live outside the model.**
The prompt is a hint, and Cedar is the lock. Every tool call goes through the AgentCore Gateway, where:

- identity comes from a JWT;
- interceptors mask PII and rate-limit;
- a Cedar policy engine decides what each persona may do.

The agent diagnoses and *recommends* fixes such as a rollback. It can never restart, scale or roll back anything itself.
